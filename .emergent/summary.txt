<product_requirements>
The goal is to build ProAgentTools, an AI-powered platform for real estate agents. The application's core features are:
1.  An AI Interior Design Model interface, initially using Replicate, later migrating to RunPod.
2.  Wrappers for 20-30 GPT concepts (e.g., property descriptions).
3.  A tiered/credit-based revenue model.
4.  Referral bonuses for new agents.

The MVP focused on the Interior Design Model:
-   **Initial Build**: Basic UI for image upload and processing via Replicate.
-   **Stability & Performance**: Resolved Replicate model access, database issues, output format, and implemented async processing for cold boot timeouts.
-   **Model Switching**: Migrated from Replicate to a custom RunPod serverless endpoint, with a temporary fallback to Replicate due to RunPod  issues.
-   **Advanced Interior Design UI**: Added user selections for Room Type (Living Room, Bedroom, Kitchen, Dining Room, Bathroom), Fictitious Interior Designers (name + 1-sentence description), and Color Schemes. This data is used by an OpenAI Assistant to generate custom image prompts. The UI layout for these selections was refined to be row-based.
-   **Designer and Color Scheme Data Integration**: Replace placeholder data with actual values from  and .
-   **Designer Images & Bios**: Display designer images in small circles and show full bios in a hover/click modal.
-   **UI Flow Redesign**: Restructure the interior design process to be sequential: upload, select room, select designer, select colors, then submit.
-   **Midjourney-style Features**: Implement higher resolution image output, a download button, image history, and a queue system allowing multiple requests.
-   **Permanent Image Storage**: Store generated images permanently on the server instead of temporary Replicate URLs.
-   **Layout Refinement**: Create a two-column layout with a left sidebar for queue/history and a right column for settings, featuring scrollable designer/color sections.
-   **Thumbnail Click-to-Enlarge**: Add a modal to view larger versions of history thumbnails.
-   **Business Infrastructure (Admin & Payments)**: Build an admin backend for user/payment/analytics management, a credit system (configurable rates, rollover, subscription-based), and a referral system (100/100 credits, permanent, redeemable by paying members). Authentication using email/password is the initial focus.
</product_requirements>

<current_work>
The ProAgentTools application is currently a highly functional AI interior design platform, featuring a professional Midjourney-style interface. The UI is structured into a two-column layout: a compact left sidebar displays real-time queue status and an always-visible history of designs with clickable thumbnails (which open a modal to view larger images, download, or delete). The right column hosts the design settings, following a logical step-by-step flow (upload, room type, designer style, color scheme) with compact, scrollable sections for designers and color schemes. Designers now feature real images and bios, and generated images are high-resolution, stored permanently on the server, and automatically refresh in the history.

Crucially, the backend has been fortified with a complete business infrastructure. This includes a robust JWT-based user authentication system, a credit system that deducts credits for AI tool usage, and a foundational admin backend that allows for user management, analytics tracking, and configurable tool rates. Protected endpoints ensure secure access, and new users are automatically granted initial credits with referral code generation. All core business logic is in place on the backend, ready for the corresponding frontend UI to be built.
</current_work>
