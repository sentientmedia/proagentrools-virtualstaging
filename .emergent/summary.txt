<product_requirements>
The goal is to build ProAgentTools, an AI-powered platform for real estate agents. The application comprises:
1.  An interface for an AI Interior Design Model (initially Replicate, later RunPod).
2.  Wrappers for 20-30 GPT concepts (e.g., property descriptions, market analysis, email templates).
3.  A tiered/credit-based revenue model.
4.  Referral bonuses for new agents.

The initial MVP focused on the Interior Design Model interface. The application, built with React frontend, FastAPI backend, and MongoDB, progressed through several iterations:
-   **Initial Build**: Basic UI for image upload, processing via Replicate, and GPT tool integration.
-   **Stability Fixes**: Resolved Replicate model access (404), database history issues, and Replicate output format handling.
-   **Performance Enhancement**: Implemented async processing and status polling to address Replicate cold boot timeouts.
-   **Model Switching**: Migrated from Replicate to a custom RunPod serverless endpoint.
-   **Advanced Interior Design**: Added user selections for Room Type (Living Room, Bedroom, Kitchen, Dining Room, Bathroom), Fictitious Interior Designers (name + 1-sentence description), and Color Schemes. This data is to be used by an OpenAI Assistant to generate custom image prompts for the AI interior design model. The UI layout for these selections was refined to be row-based.
</product_requirements>
